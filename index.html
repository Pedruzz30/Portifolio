Sobre mim

Ainda aprendendo, mas já levando código a sério

Sou Pedro Henrique, estudante de Engenharia de Software. Entrei de cabeça no back-end em 2024 e desde então venho praticando Java, POO, Spring Boot, APIs REST, JPA/Hibernate e MongoDB.

Para mim, código bom não é só o que roda. Ele precisa ser claro para quem lê, fácil de testar e simples de mudar quando o projeto cresce. É por isso que estudo SOLID, Clean Code e arquitetura com atenção.

Hoje procuro minha primeira oportunidade como Java Júnior, em um time onde eu possa aprender com gente experiente e contribuir de verdade.

  • Escrever código que outras pessoas entendam
  • Construir APIs REST com cuidado
  • Estudar todo dia, sem pular a base
  • Cumprir combinados e pedir feedback
